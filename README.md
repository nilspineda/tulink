# TuLink

TuLink es una plataforma para crear tu perfil público con enlaces. Diseñado para ser rápido, sencillo y moderno.

## Empezar

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) para comenzar.

## Funcionalidades

- Crea y personaliza tu perfil público
- Gestiona tus enlaces
- Vista previa en tiempo real
- Genera códigos QR para compartir tu perfil

## Tecnologías

- Next.js, React, TypeScript
- Tailwind CSS
- Supabase (Base de datos y autenticación)
- qrcode.react (generación de QR)
